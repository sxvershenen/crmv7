# Обзор / Dashboard

## Обзор - dashboard
Settings-bar: [Все / Мои] [icon настройка] - настроить какие блоки отображать.
Две половины. Левая Внимание/риски (занимает 2/3 ширины), правая о сегодняшних (1/3 ширины).
Записи внутри блоков разделять дивайдером.

### Внимание:
---
Заголовок блока: [icon] Конфликты (counter)

Содержимое внутри блока слева
title: Что произошло коротко.
sub: Подробности о конфликте.
#ID - Клиент - Что бронировалось

Содержимое карточки справа: Время брони, secondary: date
