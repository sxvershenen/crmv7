# Программы / проведения / регистрации

> В исходнике заголовок строки 219 повторяет «Ресурсы», но содержание ниже относится к программам. Текст требований не переписан.

## Ресурсы (настройка и мониторинг)
Navigate + Settings-bar: Шаблоны / Проведения / Регистрации     справа [<][Date Picker for Agenda / Диапазон для Table][>] если вкладка проведения > [Таблица / Vertical-Scheduler 3 дня / неделя]  [Фильтры для всех вкладок] [Icon settings category]

В разделе категории мы можем просмотреть или создать новую категорию (название типа семейные, детские, сезонные и т.д.) + иконка + цвет.
Вид отображения - карточки.

### Список всех регистраций. 
Таблица:
[ico programm] Название + secondary дата ниже / Клиент рядом сереньким ico_person # + ниже secondary телефон / стоимость + secondary долг / статус with fast change / комментарий / ответственный ava [кнопка доп. действий]

Для мобилок придумать адаптацию лаконичную карточками.
