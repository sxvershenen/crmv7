# Источники истины и разрешение конфликтов

## Приоритет

- **UI/визуал/компоновка/редакторы:** более поздний `reference/original-ui-visual.md`.
- **Предметная модель/backend/PostgreSQL/API/security:** общее full-stack ТЗ, если оно не конфликтует с более поздними указаниями пользователя.
- **Порядок разработки:** текущая команда пользователя — design system → frontend → backend → site.
- **Код:** показывает текущее состояние реализации, но не отменяет целевое ТЗ. При расхождении не закреплять ошибку кода как новое правило.

## Уже разрешённые конфликты

1. `route-driven overlay` → заменён отдельными route-driven edit/create страницами.
2. `Lucide Icons` → пользовательская иконография `Tabler Icons`.
3. обязательный full-stack vertical slice с первого UI → заменён фазовым порядком текущего проекта.
4. запрет mock runtime → до backend разрешены **только локальные fixtures**, изолированные от UI и бизнес-логики.

Подробности: `../DECISIONS.md`, `../reference/conflict-map.md`.
