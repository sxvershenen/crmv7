# Scope платформы

Платформа «Свистоплясово» состоит из четырёх логических частей:

1. **CRM** — ежедневная работа сотрудников: заявки, клиенты, брони, ресурсы, программы, мероприятия, задачи, оплаты, уведомления, расписания, аналитика.
2. **Backend + PostgreSQL** — единая предметная модель, бизнес-правила, API, права, аудит, availability, платежи, concurrency.
3. **Public site** — многостраничный сайт, который получает данные только через public API и создаёт заявки, а не подтверждённые брони.
4. **Technical/content admin** — контент, SEO, медиа, справочники, пользователи/роли, интеграции и публикация.

## Не входит в первый релиз

Онлайн-эквайринг, полноценная бухгалтерия/касса/фискализация, ЭДО, склад/закупки, housekeeping, динамическое ценообразование, личный кабинет клиента, отдельное мобильное приложение, микросервисы, автоматическое подтверждение брони с публичного сайта.
