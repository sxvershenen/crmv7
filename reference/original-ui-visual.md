# Общие правила
[ico] почти везде должен содержать подложку, если это важное или о ресурсах = цветная иконка и подложка с оттенком.
#ID подразумевает номер заказ-наряда.
Ответственные отображаются аватарками 24х24px, если нет то кнопкой "+ Назначить".
Всё что можно лаконизировать иконками - лаконизировать иконками! Особенно слово гостей менять иконкой person.
Все карточки должны быть кликабельны. Если отображение таблицей - столбики сортируемые.
Внутри edit/create страниц поля должны быть сразу редактируемыми.
Формат дат: Завтра, 11:00 или 06 июл, 11:00
Старайся не делать карточки внутри карточки внутри карточки, иногда лучше использовать разделение дивайдерами.
