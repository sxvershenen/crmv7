## Decisions drafted

- separate `apps/admin` on shared CRM design system;
- owner/source markers and public profiles instead of operational duplication;
- three content modes: strict blocks, reusable versions, controlled custom code;
- global slot inheritance with inherit/override/disabled;
- immediate draft preview and atomic gated production release;
- Astro server/hybrid as target, static rebuild only explicit fallback;
- WebP media pipeline + usage graph;
- three API namespaces and per-consumer Outbox delivery;
- first-party pseudonymous analytics, no raw IP/form PII in events;
- Metrika as consent-gated comparative integration, not authority.
